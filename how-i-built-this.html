How I Built This Website Using Copilot, GitHub, and Microsoft 365

Most advice says “building a website is easy”. It isn’t, especially when you don’t know where to start and you don’t want to disappear into templates, plugins, or subscriptions.

This page explains exactly how I built this site using Copilot, GitHub Pages, and the Microsoft 365 tools I already use to run my work.

Why I Didn’t Use Wix, Squarespace, or WordPress

I didn’t want:

  • Monthly fees and upsells
  • Bloated templates and slow pages
  • Plugin maintenance and breakage
  • Another platform owning my content

I wanted something simple, fast, under my control, and easy to update. Microsoft 365 gives me almost everything I need to run a micro‑business – except a website builder. So I built the missing piece myself.

Copilot as a Thinking Partner

Copilot helped me with the parts that usually block people from starting:

  • Designing the structure of the site and pages
  • Drafting and refining the content
  • Generating the HTML for each page
  • Fixing layout and navigation issues
  • Keeping tone and language consistent

I didn’t need to become a web designer. I used Copilot to think through the site with me and turn that into clean, static pages.

GitHub Pages for Hosting

GitHub Pages gives me:

  • Free hosting and SSL
  • Fast global delivery
  • No ads, no branding, no surprises
  • A simple “files in a repo = live website” model

I created a repository, added the HTML files Copilot and I produced, and pointed my domain pcnetworking.co.uk at GitHub Pages. No control panel, no installer, no CMS.

How Microsoft 365 Fits Around the Website

Once the website existed, the rest of my Microsoft 365 tools suddenly became much more useful. The site is now the front door for:

  • Microsoft Bookings – clients can book sessions directly from the site
  • Teams Premium – branded online meetings generated automatically from bookings
  • Microsoft Forms – intake and feedback forms before and after sessions
  • SharePoint and OneDrive – storing client materials and templates
  • Outlook – email follow‑up, confirmations, and signatures that point back here

The website doesn’t try to do everything. It does one thing well: give people a clear place to understand what I do and take the next step.

The Result

This site is intentionally simple:

  • No animations, sliders, or distractions
  • Fast to load and easy to read
  • Low maintenance and low risk
  • Aligned with how I actually work with clients

It costs me nothing per month to host, and it integrates cleanly with the tools I already pay for in Microsoft 365.

If You’re Stuck at “I Don’t Know Where to Start”
