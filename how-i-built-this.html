How I Built This Website

This site is built the same way I work: simple, fast, and under my control.

Why I Didn’t Use Wix, Squarespace, or WordPress

I didn’t want:

  • Monthly fees and upsells
  • Bloated templates and slow pages
  • Plugins breaking every other week
  • A platform sitting between me and my own content

Copilot as a Thinking Partner

Copilot helped me with:

  • Structuring the pages
  • Drafting and refining the content
  • Generating the HTML skeletons
  • Fixing layout issues
  • Keeping tone consistent

GitHub Pages for Hosting

GitHub Pages gives me:

  • Free hosting and SSL
  • Fast global delivery
  • No ads, no branding, no surprises
  • A simple “files in a repo = live website” model

How Microsoft 365 Fits Around the Website

The website is static on purpose. The real work happens in Microsoft 365:

  • Outlook for email
  • SharePoint/OneDrive for files
  • Teams for calls and sessions
  • Planner/To Do for tracking work
